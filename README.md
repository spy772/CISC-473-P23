# CISC-473-P23

## Setup & Installation

1. Clone the repo
2. Activate the virtual environment.

### Windows: (run in Command Prompt)

```
.venv\Scripts\activate.bat
```

### Mac: (run in Terminal)

```
source .venv\bin\activate
```

3. Install the requirements:

```
pip install
```

4. Run your program of choice.
